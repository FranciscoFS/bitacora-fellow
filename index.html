Sincronización

Puedes trabajar en este dispositivo. Para compartir tu bitácora entre dispositivos, conecta tu repositorio privado de GitHub.

Opciones avanzadas

Cómo conectar GitHub
  1. Crea un repositorio privado llamado bitacora-rodilla-data.
  2. En GitHub, abre Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  3. Elige sólo ese repositorio y habilita Contents: Read and write.
  4. Pega el token, prueba la conexión y guarda la configuración.

Importar y exportar

El respaldo incluye todos los casos, metas y criterio de conteo. No contiene el token.

Publicar la app en GitHub Pages
  1. Sube los archivos de la app a un repositorio público, sin datos de pacientes.
  2. En Settings → Pages, elige Deploy from a branch, rama main y carpeta raíz.
  3. Abre la URL en cada dispositivo y configura el mismo repositorio privado.
