# Catálogo de Trauma

Nombres solicitados por el usuario para el servicio:

- Fractura Fémur Distal
- Fractura Periprotésica
- Fractura Platillos Tibiales
- Fractura de Rótula
- Fractura Avulsiva Espinas Tibiales LCA / LCP

Todos se clasifican en Trauma en los selectores de procedimiento principal y asociado. Los otros procedimientos de Trauma se conservan.

Los nombres anteriores de meseta tibial, cóndilo/supracondílea femoral y rótula se reconocen como equivalentes de las nuevas etiquetas. Los casos mantienen sus identificadores y las etiquetas anteriores se conservan en el JSON como referencia. Las metas también se reconocen bajo el nombre actualizado; si confluyen dos metas equivalentes, se conserva el objetivo mayor.

La clasificación por área usa los límites del catálogo en lugar de posiciones numéricas fijas, para que añadir o mover procedimientos no desplace las demás áreas.
